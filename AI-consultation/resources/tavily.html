Web search in U-M GPT with Tavily

M-Connectors link U-M GPT to external tools and services. Tavily provides web search, helping U-M GPT find up-to-date information and source links for research.

If Tavily appears in your connector catalog, follow these steps:

  1. 1

    Open the connector catalog

    Sign in to U-M GPT. You must select the GPT-5.6 Sol (agent) model to use this connector. Open the three-dot Options menu in the lower-left corner and select Manage Connectors.

  2. 2

    Install Tavily

    Find Tavily and click Install. If Finish Authentication appears, click it and complete the connection prompts.

  3. 3

    Enable it for your conversation

    Return to U-M GPT. Click No Active Connectors (or the active-connectors button) in the upper-right corner, toggle Tavily on, and click Done.

  4. 4

    Try a web search

    Ask: “Use Tavily to search the web for recent AI-assisted mathematics research. Include dates and source links.”

These steps follow U-M ITS’s official M-Connector setup instructions. Connector availability may vary. U-M’s public guide does not specify whether Tavily requires a separate account or API key; follow any prompts shown during installation.
